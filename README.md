# Student Grade Calculator - Java Internship Task 2

This is my Task 2 for Java Internship at **DecodeLabs**.

### 📝 Project Description
A console-based Java application that helps students and teachers to manage and calculate grades. The user enters subject names and marks, and the system calculates total marks, average percentage, overall grade, highest and lowest scoring subjects.

### 🚀 Features
- Input subject-wise marks using HashMap
- Calculate Total Marks & Average Percentage
- Auto Grade Calculation (A+, A, B, C, Fail)
- Find Highest & Lowest scoring subject using Collections
- Sorted result display
- Input validation for marks

### 🛠️ Tech Stack & DSA Concepts Used
- **Language:** Java
- **DSA Concepts:** HashMap, ArrayList, Collections.sort(), Loops, Conditionals
- **Concepts:** OOP, Input Validation

### ▶️ How to Run
1. Clone the repository: `git clone https://github.com/javeriaasif/DecodeLabs_StudentGrade_Calculator.git`
2. Compile: `javac StudentGradeCalculator.java`
3. Run: `java StudentGradeCalculator`
